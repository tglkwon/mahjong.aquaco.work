🎯 서비스 UI 테스트 기능 완전 은닉 & 원클릭 모바일 테스트 세션

EC2 실제 배포 전 일반 사용자 UI에서 테스트 기능 및 랩 전환 링크를 완벽히 숨기고, 대기열(/queue)을 사이드바에 공식 노출하며, 개발자가 "모바일 테스트 서버 열어줘" 한 마디로 PC 전송 파라미터가 모두 주입된 원클릭 링크를 받는 통합 오케스트레이션 번들을 구축합니다.

🌐 일반 사용자 서비스 뷰 Production Mode

일반 사용자 화면에서는 테스트 랩이나 PC 전송 모드 관련 UI가 100% 은닉됩니다.

[사이드바 메뉴]
🏠 홈노출
📊 점수 계산기노출
🎲 우마/오카 계산기노출
📹 점수판 스캔 (/scan_score)노출
🀄 대기열 & 자리 추첨 (/queue)추가됨
🧪 테스트 스캔 (/scan_score_test)제거됨
ℹ️ 소개노출
• 대기열 (/queue): 점수 스캔 버튼 ➔ /scan_score 이동
• 착석 (/seat): 자동 카운트다운/버튼 ➔ /scan_score 이동
• 점수 입력 (/scan_score): 🧪 테스트 Lab 전환 탭 비노출

🧪 개발자 온디맨드 뷰 Developer Mode

URL 직접 접속(/scan_score_test 또는 ?testMode=true) 시 모든 테스트 기능이 활성화됩니다.

[개발자 랩 기능 정상 가동]
🧪 PC 전송 테스트 브리지 (8899)정상
🔬 작탁 기종 진단 (REX 3 / JP-EX)정상
📡 테이블 1 실시간 웹소켓/폴링 연동정상
🔄 원본 프레임 90도 회전/진단 패널정상
📹 일반 서비스 복귀 링크 노출정상
• 파라미터 지원: dropUrl, dropPin, device 자동 연동
• 다기종 지원: rex3, jpex, jpcolor 기기별 디렉터리 분기

⚡ 원클릭 모바일 테스트 세션 번들 워크플로우 (Orchestration)

1

개발자 트리거 요청

채팅창에 "모바일 테스트 서버 열어줘" 또는 "테스트 세션 시작" 입력

2

자동 백그라운드 번들 구동 (scripts/start-test-session.ps1)

React 개발 서버(3000) 및 mobile-drop 파이썬 수신기(8899) 동시 구동 + Cloudflare 듀얼 터널 자동 연결

pwsh.exe -File scripts/start-test-session.ps1 -Port 3000 -DropPort 8899 -Device rex3
3

세션 메타데이터 (.test-session.json) 생성

실행 중인 프로세스들의 PID와 터널 URL을 저장하여 추후 안전한 일괄 종료를 보장합니다.

항목설명
web_tunnel_urlReact 개발 서버 Cloudflare HTTPS 공개 URL
drop_tunnel_urlmobile-drop 수신 서버 Cloudflare HTTPS 공개 URL
pin6자리 난수 보안 인증 PIN
pidsNode.js(3000), Python(8899), cloudflared 2기 PID 기록
4

원클릭 모바일 테스트 URL 즉시 제공

모바일 브라우저에서 탭하는 즉시 PC 수신기와 페어링 완료 상태로 스캔 랩이 열립니다.

https://<web-tunnel>.trycloudflare.com/scan_score_test?dropUrl=https://<drop-tunnel>.trycloudflare.com/upload&dropPin=123456&device=rex3
5

안전한 세션 일괄 종료 (scripts/stop-test-session.ps1)

테스트 완료 후 "서버 닫아줘" 요청 시 .test-session.json의 PID를 기반으로 모든 프로세스를 즉시 강제 종료하고 정리합니다.
