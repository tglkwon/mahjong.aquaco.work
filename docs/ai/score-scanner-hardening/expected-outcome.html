점수 스캐너 실전 개선 6대 핵심 아키텍처

실제 마장 촬영 영상 데이터 분석을 기반으로, 실패 원인 추적 진단 메타데이터·뷰파인더 좌표 완전 일치·적응형 빨강 보정 폴백·엄격한 자동 확정 안전 게이트를 도입합니다.

원칙 1 진단 메타데이터 Sidecar JSON

프레임마다가 아닌 대표 프레임과 종료 시점에만 실패 원인을 찾는 필수 값 수집 (deviceId 제외, captureId 연동).

{ "captureId": "rex3_scan_2026-09-27...", "camera": { "res": "1920x1080", "fps": 30, "orientation": "portrait" }, "roi": { "sy": 0.25, "sHeight": 0.50, "scale": 0.5 }, "stage": "score_validated", "redCandidates": 482, "digitGroups": 4, "decoded": ["250", "250", "250", "250"], "sumValid": true, "exitReason": "consensus_achieved" }

원칙 2 뷰파인더-분석 ROI 좌표 동기화 (WYSIWYG)

세로 원본 중앙 50%를 가로 ROI로 유지하고, 화면 미리보기와 캔버스 분석 좌표를 1:1 일치시키며 내부 80% 안전 가이드를 제공합니다.

내부 80% 점수 조준 가이드

화면 밖 25% 상/하단 여백 자동 마스킹 -> 번호 잘림 방지

원칙 3 & 4 2단계 빨강 검출 & 3중 자동 확정 안전 게이트

1. frame_ready
->
2. red_candidates (1차 엄격 / 실패시 적응형 Otsu)
->
3. digit_groups (기하 검증)
->
4. decoded (세그먼트 판독)
->
5. score_validated (합계 10만점)
A

1차 경로: 엄격한 고속 판독 (Fast Path)

고정 임계값(R > 180, R > G*1.6)으로 2ms 이내 초고속 판독 유지.

B

2차 경로: 실패 시에만 R - max(G,B) 적응형 Otsu 보정 (Fallback)

어두운 마장 조명 대응. 상/하한선(35~120) 클램핑과 7세그먼트 크기 조건으로 오탐 차단.

C

3중 안전 게이트: 불확실 판독 자동 확정 원천 차단

1. 4개 점수 배치 기하 검증(T자/다이아몬드) + 2. 점수 총합 100% 일치 + 3. 3회 연속 프레임 일치 조건 미통과 시 미확정 유지 후 직접 입력 안내.

원칙 5 실전 영상 정량 평가 프레임워크

research-data 내 실제 성공/실패 영상에 정답 라벨을 부착하여 벤치마크 검증.

- 4자리 전체 정답률: 실전 영상 기준 측정
- 오인식 자동 확정률: 0.0% 절대 사수 (최우선 안전 기준)
- 인식 지연시간: 중앙값(Median) 및 95백분위(P95) 모니터링

원칙 6 수동 작탁 선택 절대 우선권

드롭다운에서 사용자가 REXX 3 또는 JP-EX를 수동 선택하면 자동 감지가 모델을 덮어쓰지 못하도록 엄격 격리.

- 자동 감지 모드: 카메라 프레임 분석에 따라 자동 전환
- 수동 지정 모드: 사용자 선택 모델 완전 고정 (분석기 내부 재할당 차단)
