1. 워크플로 대조 (Before vs After)

기존 번거로운 방식 (Before) 비효율 3단계
  • 1
    스마트폰으로 점수판 인식 시도
  • 2
    인식 상태를 폰 버튼으로 수동 스크린샷 찍거나, 카메라 앱을 따로 열어 별도 동영상 촬영
  • 3
    클라우드나 메신저, 사후 파일 전송을 통해 PC로 수동 이동 후 디버깅 시작
mobile-drop 연동 방식 (After) 자동 1단계
  • 1
    PC에서 mobile-drop 세션 시작 (URL & PIN 발급)
  • 2
    모바일 인식 페이지 상단에 [🧪 PC 전송 모드] 연결 (URL 파라미터로 원클릭 자동 페어링 가능)
  • 3
    점수판 촬영/스캔 즉시 로컬 OCR 인식 + 영상/스냅샷 파일이 PC ./uploads/ 로 청크 직송!

3. 설계 결정 사항 및 범위 경계 (Boundaries)

항목 구분 내용 및 추론
통신 보안 및 경로 범위 내 Cloudflare Quick Tunnel HTTPS 엔드포인트 필수 사용 (모바일 HTTPS 사이트에서 HTTP 직접 호출 시 Mixed Content 보안 차단 방지). 6자리 PIN 인증.
영상/사진 전송 규격 범위 내 mobile-drop 규격 준수: 8MB 청크 분할 전송(/upload/chunk) 및 병합(/upload/complete). 대용량 영상도 타임아웃 없이 안정 전송.
임시성 및 가역성 범위 내 상용 유저 영향 없는 개발자 전용 토글/쿼리스트링 구동. URL 파라미터(?dropUrl=...&dropPin=...)로 접속 시 자동 활성화.
세션 종료 방식 (질문) 결정 대기 옵션 A: 1개 전송 후 즉시 종료 (mobile-drop 기본) vs 옵션 B: 여러 판을 연속 테스트할 수 있는 다중 전송(Continuous) 모드.
외부 스토리지 저장 제외 범위 AWS S3나 별도 DB는 일절 사용하지 않으며, 오직 로컬 PC 워크스페이스(uploads/)에만 직접 저장.
