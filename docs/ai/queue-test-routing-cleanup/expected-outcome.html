1. 점수 입력 페이지 일원화 (Route Consolidation)

기존 (이원화)
운영: /scan_score
테스트: /scan_score_test
❌ 화면/경로가 2개로 나뉘어 대기열 및 QR 연동 시 경로 혼선
❌ 대기열에서 일반 점수판으로 이동 시 전송 기능이 있는 테스트 모드 유실
개선 후 (단일 경로 일원화)
모든 사용자: /scan_score
(구형 /scan_score_test 접속 시 쿼리 파라미터 유지한 채 자동 리다이렉트)
✅ 모든 화면(대기열, 좌석, 메인)이 오직 /scan_score 하나만 참조
✅ 인쇄된 QR이나 기존 북마크 100% 하위 호환

2. 테스트 서버(mobile-drop) 상태 기반 조건부 전송

케이스 A: 테스트 세션 가동 중 (터널 열림)
mobile-drop GET /status ➔ 200 OK (ready)
🟢 PC 전송 모드 자동 활성화
✅ 실시간 점수판 촬영 시 PC(research-data/rex3)로 스냅샷/영상 자동 업로드
✅ 테스트용 10만점 자동 채우기 버튼 노출
케이스 B: 일반 운영 중 (테스트 세션 닫힘)
mobile-drop GET /status ➔ 접속 불가 / 미설정
⚪ 일반 운영 모드 (데이터 전송 미수행)
✅ 모바일 로컬에서만 점수 인식 수행, 외부 전송 네트워크 비용 0
✅ 손님용 일반 마작장 운영 화면으로 깔끔하게 동작

3. 자리 추첨 후 대기열 제외 및 세션 갱신

기존 (BEFORE)
❌ 과거 세션 착석자 4명 고착 및 신규 대기자 4명 대기열에 방치
#1 신규테스터1대기 중 (제외 안 됨)
