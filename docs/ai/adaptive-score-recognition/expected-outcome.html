Phase 1 Design Preview

조준 가이드 연동 및 밝기·대비 적응형 점수판 인식

WYSIWYG 조준 영역 분석, 2단계 적응형 정규화, 원본 픽셀 상대 대비 기반 7세그먼트 해석 설계 프리뷰

1. 조준 가이드와 실제 분석 영역 1:1 일치 (WYSIWYG)
기존 방식 (불일치)

- 화면에는 w-[94%], h-[78%] 조준 상자 표시
- 내부 로직은 화면과 무관하게 세로 중앙 50%를 맹목적으로 추출
- 결과: 조준창 밖의 조명/손/잡음이 유입되고, 상하단 숫자가 잘리는 오작동 발생

[전체 카메라 스트림: 1080x1920] +-------------------------------+ | (외부 조명/주사위통 잡음 유입) | | +-----------------------+ | | | 화면의 조준창 (실제 조준) | | |---|- - - - - - - - - - - -|---| <- 25% 라인 | | [하단][우측][상단][좌측] | | <- 세로 50% 강제 크롭 |---|- - - - - - - - - - - -|---| <- 75% 라인 | | (조준창 아래 숫자는 절단) | | +-------------------------------+
개선 방식 (100% 동기화)

- CSS object-cover 좌표를 역변환하여 조준창 영역만 정확히 크롭
- 잘라낸 영역을 최대 960px로 축소하여 분석 캔버스에 주입
- 결과: 점수판 내부 4개 점수 영역만 안전하게 캡처되어 오탐지 원천 차단

[전체 카메라 스트림: 1080x1920] +-------------------------------+ | (바깥 영역 완전 배제) | | +-----------------------+ | | | ★ 조준창 1:1 정확 크롭 | | | | [하단][우측][상단][좌측] | | | | (4개 점수 완벽 포함) | | | +-----------------------+ | | (점수판 외곽 잡음 0%) | +-------------------------------+
2. 개선된 적응형 인식 처리 파이프라인
1
조준 창 영역 크롭 & 최대 960px 축소
사용자가 바라보는 조준 가이드 내부 사각형만 잘라내어 해상도 최적화 (가로/세로 최대 960px)
2
1단계: 조준창 전체 대략적 밝기 기준 계산 (샘플링)
격자 샘플링(4px 간격)으로 배경과 LED의 밝기 분포를 빠르게 파악하여 적응형 후보 마스크 생성
3
숫자 영역 탐색 & 4개 점수 표시부 군집화
기존 연결요소(Connected Component) 탐색 및 가로/세로 배치 알고리즘으로 4개 플레이어 표시 영역 확정
4
2단계: 4개 점수 표시부별 밝기 기준 세부 재조정
한쪽 점수판에만 천장 조명이 반사되거나 그림자가 져도, 4개 점수판 각각의 독립 기준값으로 국소 정규화
5
원본 픽셀 상대 대비 기반 7세그먼트 막대 판정
이진 마스크 밀도 대신 원본 RGB의 중심 밝기와 인접 내부 공간(캐비티) 배경의 상대 대비를 비교하여 확정
6
숫자 해석 & 4인 합계 검증 & 프레임 일치 확인
합계 검증(startingScore * 4) 및 연속 3프레임 일치 시 자동 확정 (불확실 판정 시 자동 채택 차단)
3. 막대 판정 분리: 번진 빛(Flare/Bloom)으로 인한 0 → 8 오인식 원천 차단

숫자 '0'의 중앙 막대(G 세그먼트)는 꺼져 있으나, 외곽의 A, B, C, D, E, F 세그먼트에서 방출된 강한 빛이 중앙으로 번집니다. 기존의 이진 마스크 밀도 검사는 이 번진 빛을 켜진 막대로 오판하여 '0'을 '8'로 잘못 읽는 문제가 있었습니다.

기존: 이진 마스크 밀도 판정 (오탐지 발생)

❌ 중앙 G 세그먼트에 번진 붉은빛이 마스크 밀도 임계값을 초과하여 '8'로 잘못 인식됨.

개선: 원본 픽셀 중심-캐비티 상대 대비 판정 (해결)

✅ 막대 중심과 인접 상·하 내부 캐비티의 명암비(Peak Contrast)를 비교하므로, 번진 빛과 실제 켜진 막대를 100% 구별하여 정확히 '0'으로 판정.

4. 검증 지표 및 기존 방식 대비 개선 목표
지표 기존 (3-Pass 고정/완화/Otsu) 개선 (적응형 밝기 + 원본 상대 대비) 합격 기준
네 점수 전체 정답률 조명 반사 시 위치 탐색 실패 빈발 조준창 크롭 + 4개 영역별 국소 정규화로 안정 확보 기존 픽스처 100% + 현장 영상 향상
0 / 8 오인식 발생률 LED 번짐 시 중앙 막대 오인식 위험 존재 중심-캐비티 피크 대비 비교로 원천 차단 0 / 8 관련 오판율 0.0%
잘못된 점수 자동 채택률 0.0% (합계 검증 + 3회 일치 유지) 0.0% (대비 불명확 시 불확실 판정 추가) 엄격한 0.0% 불변 유지
프레임당 처리 시간 최대 3회 패스 반복 시 ~25ms 단일 적응형 패스 + 국소 막대 샘플링 (~10ms) 프레임당 25ms 이하
