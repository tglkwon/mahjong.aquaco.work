## 맥락과 목표 결과
의도와 명세 리비전 1의 모바일 실시간 스캔을 구현한 뒤 기존 영상으로 연속 인식, 단일 초안 자동 캡처, 중복 방지, 플레이어 배정을 입증한다. 사람의 최종 확인을 유지한다.

## 저장소 상태와 제약
기존 REXX 3 인식기, 검토 컴포넌트, 한 자리 이동, 사진·수동 입력을 재사용한다. 무관한 작업 트리 변경을 보존한다. 배포나 터널을 활성화하거나 실물 휴대폰 검증을 주장하지 않는다.

## 변경 지도

## TDD 순서
안정 판정과 카메라 수명주기의 새 실패 테스트를 먼저 실행한 후 최소 상태·미디어 로직을 구현한다. 검토 전달 연결 전 UI 동작 테스트를 추가한다. 통과 상태에서만 리팩터링한다. 정확한 실패·통과 결과를 기록하며 실행하지 않은 테스트 코드로 실패 단계를 추정하지 않는다.

## E2E 시나리오
실제 REXX 3 영상으로 네 안정 점수와 검토 초안 하나를 만들고 카메라를 종료한다. 확인 전 게임은 기록되지 않는다. 이동 한 번에 플레이어를 한 자리씩 옮기고 네 번이면 원래 배정으로 복귀한다. 무효·변화 관측은 캡처하지 않는다. 취소·숨김·해제는 이후 캡처를 막고 늦은 권한 응답까지 모든 트랙을 폐기한다. 재스캔은 새 세션이다.

## 품질 게이트
집중 테스트, 전체 Jest, TypeScript, 프로덕션 빌드, 브라우저 시나리오, 독립 리뷰, 한영 구조 검증, 최종 동기화 검증을 수행한다. 미실행 검사는 이유와 영향을 기록한다. 휴대폰 정확도는 방문 전 게이트에서 제외한다.

## 위험, 마이그레이션, 롤백
반복 오인식도 안정성과 합계를 충족할 수 있으므로 사람 확인을 유지한다. 오래되거나 겹치는 미디어 콜백은 카메라 누수·초안 중복을 만들 수 있으므로 세대 가드와 수명주기 테스트로 탐지한다. 마이그레이션은 없다. 사진·수동 입력과 무관한 로컬 작업을 보존하며 실시간 스캔 변경만 되돌린다.

## 완료 증거
