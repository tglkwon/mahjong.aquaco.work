## 최초 요청
오늘은 가게 갈 일이 없으니 가게 방문 전: 기존 점수판 영상으로 연속 인식·자동 캡처·중복 방지·플레이어 배정을 검증을 해보자.

요청 요약: 앞서 논의한 모바일 웹 실시간 스캔을 구현하고, 가게 방문에 앞서 기존 점수판 영상으로 검증한다.

## 문제와 근거
대화에서 사진 입력, 재사용 가능한 REXX 3 인식기, 로컬 샘플 영상과 실시간 카메라 흐름을 확인했다. 이전 테스트 통과 보고만으로 현재 실시간 스캔 동작이나 실제 휴대폰 정확도를 입증할 수는 없다.

## 원하는 결과
모바일 웹페이지에서 후면 카메라를 켜고 연속 프레임을 기기 내에서 인식한다. 안정된 결과를 한 번 자동 캡처하되 기록 전 사람의 확인과 플레이어 배정을 유지한다.

## 범위
REXX 3 전용, 카메라 수명주기, 연속 프레임 안정 판정, 초안 자동 캡처, 중복 방지, 플레이어 배정 한 자리 이동, 사진·수동 입력 대안, 기존 실제 영상 파생본을 이용한 브라우저 검증.

## 제외 범위
다른 작탁 기종, 최종 기록 자동 확정, 오늘의 휴대폰·가게 검증, 배포, 터널 활성화는 제외한다.

## 제약과 정책
오디오 없이 영상만 요청하고 후면 카메라를 우선한다. 영상 업로드 없이 캔버스 픽셀을 로컬 처리한다. 초당 최대 다섯 번의 새 프레임만 판독한다. 캡처, 취소, 페이지 숨김, 컴포넌트 해제 시 모든 트랙을 종료하며 취소 뒤 늦게 도착한 권한 응답의 스트림도 정리한다.

## 수용 신호
최소 1000 ms에 걸쳐 같은 네 점수가 다섯 번 이상 읽히고 설정 합계(기본 100000), 점수 단위, 서로 다른 플레이어 배정 조건을 충족하면 편집 가능한 초안 한 개를 만든다. 사람의 확인은 계속 필수다. 불안정·무효·오래된 프레임과 취소된 세션은 캡처하지 않는다. 배정 이동은 순환하며 재확인이 필요하다.

## 가정과 미해결 질문
데스크톱 브라우저 영상 재생으로 통합 흐름과 결정적 동작을 입증할 수 있지만 휴대폰 자동 초점, LED 번짐 내성, 배터리 사용량, 실제 프레임 처리 속도는 입증하지 못한다. 해당 검증은 명시적으로 연기했다. 진행을 막는 제품 결정은 없다.

## 결정 사항
내장 의도 질문 절차로 기존 합의를 정리했다. REXX 3 MVP, 동가 촬영·기록, 로컬 영상 처리, 안정된 결과 자동 캡처 후 사람 확인을 적용한다. 이미 설명하고 합의한 스캔부터 검토까지의 흐름을 구현·검증하는 작업이므로 별도 시각 미리보기는 적용하지 않으며 새 시각 승인도 필요 없다. 표준 위험의 되돌릴 수 있는 로컬 작업은 승인 범위다. 독립 리뷰에서 정확성과 카메라 정리를 점검한다.
