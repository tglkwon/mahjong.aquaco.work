## 요약
모바일 영상 스캔 뷰포트를 가로 슬롯 형태로 클리핑하고, 캔버스 인식 영역을 중앙 50% ROI로 한정하며, 7 vs 3 및 9 vs 8 7세그먼트 OCR 오인식을 해결하고, X축 기반의 견고한 T자형 레이아웃 판별과 빛 반사 내성 적응형 임계값을 구현함과 동시에, 엄격한 연속 일치 방식에서 슬라이딩 윈도우 빈도 합의 방식으로 전환하여 손떨림 환경에서도 1초 미만의 신속한 Fast-Lock을 제공합니다.

## 기능 요구사항
- REQ-001 must: 전체 높이의 무제한 비디오 표시를 컴팩트한 가로 슬롯 뷰포트(`overflow-hidden`, 물리적 제한 높이 `h-52 sm:h-60`, `object-cover object-center`)로 대체하여, 마작패(상단) 및 하단 불필요 영역을 잘라내고 모바일 수직 화면 공간을 대폭 절약합니다.
- REQ-002 must: `scoreCamera.ts`의 실시간 비디오 프레임 캔버스 드로잉 및 영상 분석을 중앙 50% 수직 ROI(y: 25%~75%)로 한정하여, 프레임당 처리 부하를 약 50% 절감하고 스캔 처리율(FPS)을 2배로 향상합니다.
- REQ-003 must: `scoreRecognition.ts`의 7세그먼트 OCR에서 중간 가로 세그먼트를 7의 대각선 획이 지나지 않는 오프셋 좌표에서 검사하여, 숫자 '7'(`1010010`)과 '3'(`1011011`)을 명확히 구분합니다.
- REQ-004 must: 선행 0이 포함된 4자리 점수(예: `0097` -> 9,700점)를 유실 없이 보존하고, 기준 합계 100,000점과 일치하는 유효 점수로 정확히 환산합니다.
- REQ-005 must: `scoreStability.ts`의 엄격한 연속 일치 방식을 슬라이딩 윈도우 빈도 합의로 대체합니다: `1500ms` 윈도우 내에서 유효한 관측값을 유지하고, 간헐적인 비유효 프레임이 발생하더라도 동일한 4인 점수 세트가 최소 간격 `100ms` 이상에서 `2`회 관측되면 즉시 `ready: true`를 발동합니다.
- REQ-006 must: `scoreCamera.ts`의 프레임 분석 간격을 `200ms`에서 `100ms`(10 FPS)로 단축하여 0.2~0.3초 Fast-Lock을 구현합니다.
- REQ-007 must: `scoreRecognition.ts`의 OCR 기하 프로브를 정밀화합니다 (`lower-left` 프로브 임계값을 `0.38`로 올리고 `cy`를 `0.64`로 조정하여 `9`가 `8`로 오인식되는 결함 차단; 숫자 `1` 종횡비 기준을 `0.33`으로 강화하여 `5`/`7` 오인식 차단; 기울어짐에 강한 X축 레이아웃 분할 `runsByX` 적용; 빛 반사 내성을 위한 적응형 적색 임계값 폴백 `r > 160 && r > g * 1.4 && r > b * 1.2` 추가).

## 비기능 요구사항
완전한 클라이언트 브라우저 내 인메모리 무네트워크 이미지 처리를 유지합니다. 모바일 기기에서 카메라 슬롯, 실시간 HUD 및 확인 폼이 스크롤 없이 한 화면에 편안하게 들어오도록 UI 반응성을 보장합니다.

## 사용자 경험과 흐름
사용자가 실시간 스캔 시작 → 컴팩트한 가로 슬롯 뷰포트(h-52)에서 카메라 실행 → 사용자가 전면 점수판 조준 → 슬롯 아래의 실시간 4인 HUD가 스크롤 없이 실시간 갱신 → 슬라이딩 윈도우 합의가 1.5초 윈도우 내 2회 일치하는 점수 세트 감지(0.2~0.3초) → 자동 캡처 발동 → 점수 확인 폼이 채워지며 동일 화면에서 즉시 확인 및 기록 가능.

## 아키텍처와 인터페이스
- UI 뷰포트: `PhotoUploadPanel.tsx`에서 `object-cover` 및 컨테이너 높이 클리핑 CSS 클래스 적용.
- 카메라 파이프라인: `scoreCamera.ts`에서 픽셀 추출 전 `drawImage` 소스 좌표 슬라이스를 통한 중앙 ROI 크롭 및 100ms 쓰로틀.
- 합의 엔진: `scoreStability.ts`의 슬라이딩 윈도우 빈도 히스토그램 트래커.
- 인식기: `scoreRecognition.ts`의 세그먼트 프로브 좌표 정밀화, X축 기하 분할 및 적응형 적색 임계값.

## 데이터와 마이그레이션

## 실패 모드와 경계 사례
작탁 모델이 AMOS REXX 3가 아니거나 숫자가 중앙 ROI를 벗어난 경우 일반 재시도, 수동 업로드 또는 직접 입력으로 폴백합니다. 극심한 빛 반사로 1500ms 내에 2회 일치 프레임을 얻지 못하더라도 합의 트래커는 에러 없이 신규 프레임을 계속 누적 버퍼링합니다.

## 보안, 개인정보, 권한
모든 프레임은 브라우저 메모리 내에만 머무릅니다. 외부로 전송되는 텔레메트리나 이미지는 일절 없습니다.
