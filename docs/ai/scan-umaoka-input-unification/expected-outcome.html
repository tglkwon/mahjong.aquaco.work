MVP 1.4 UI 개선 프리뷰

우마·오카 실시간 점수 스캔 UI 일원화 및 동적 목표 점수 연동

중복되어 혼란을 주던 스캔 패널의 점수 수동 입력 폼을 제거하고, 우마·오카 점수 기록표를 기준으로 단일화합니다.

이전 구조 (Before: 역할 중복)
  • 스캔 패널 내에 별도의 점수 입력 필드 4개 및 단위/확정 폼 존재
  • 아래쪽 우마·오카 테이블에 또다시 동/남/서/북 점수 입력 필드 존재
  • 목표 합계가 100,000점으로 고정되어 시작 점수 변경 미반영
  • 두 개의 서로 다른 확정 버튼으로 인한 사용자 혼선
개선 구조 (After: 단일 UI 워크플로우)
  • 스캔 패널은 카메라 뷰파인더, 3-dot 게이지, 라이브 HUD 전용
  • 인식된 점수가 우마·오카 테이블 편집 행으로 즉시 자동 입력
  • 우마·오카 테이블에서 직접 입력 및 증감 버튼으로 자유로운 수정
  • 시작 점수(25,000 -> 30,000) 변경 시 목표 합계(100,000 -> 120,000) 실시간 동적 반영
1
룰 설정: 시작 점수(기본 25,000) 및 반환 점수(기본 30,000) 설정 → 목표 합계(시작 점수 × 4) 자동 계산
2
실시간 스캔: 카메라를 점수판에 비추면 0.2~0.3초 내 4개 점수 감지 및 자동 캡처
3
단일 테이블 확인/수정: 우마·오카 테이블에 점수가 즉시 채워지며, 필요시 테이블에서 직접 수정
4
기록 추가 및 공유: 목표 합계 일치 확인 후 하단 기록 추가 버튼으로 원터치 누적 및 링크 생성
핵심 가치: 화면 스크롤과 중복 폼 없이, 스마트폰 한 화면에서 스캔과 우마·오카 점수 기록을 가장 직관적으로 마칠 수 있습니다.
