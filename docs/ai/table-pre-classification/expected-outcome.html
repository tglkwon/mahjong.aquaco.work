작탁 기종 사전 자동 판별 알고리즘 (Pre-classifier)

카메라가 켜지는 순간 영상 속 CHECK LED 위치와 색상을 0.01초 내에 감지하여 REXX 3 또는 JP-EX를 자동 선택하고, 필요한 경우 사용자가 수동으로 변경할 수 있는 스마트 파이프라인입니다.

REXX 3 판별 지표 AMOS REXX 3

좌측 상단 녹색 LED: CHECK 표시등이 좌측 상단에 위치

• 하단 4자리 표시 (1자리 순위 + 3자리 점수)
• 매끄러운 단색 플라스틱 베젤 및 순위 화살표 인쇄

JP-EX 판별 지표 AMOS JP-EX

우측 상단 주황색 LED: CHECK 표시등이 우측 상단에 위치

• 3자리 100점 단위 전용 (1만점 미만은 2자리 Zero-blanking)
• 카본 격자 무늬 페이스플레이트 및 곡선형 타원 베젤

스캔 및 자동 전환 흐름 (UX Flow)

1

기본값 로드 및 카메라 초기화

사용자가 이전에 사용한 기종(또는 REXX 3 기본값)으로 초기 시작합니다.

2

프레임 사전 분류기 (Pre-classifier) 1회 실행

카메라가 점수판을 비추면 상단 LED 영역을 스캔하여 녹색(좌) vs 주황색(우)을 5ms 내에 판별합니다.

3

기종 자동 동기화 & 수동 오버라이드 유지

JP-EX가 감지되면 UI 드롭다운이 AMOS JP-EX로 자동 전환되고 사용자에게 피드백을 제공합니다. 사용자가 드롭다운을 직접 변경하면 자동 전환이 중단되고 수동 선택값이 우선합니다.

AMOS JP-EX (3자리 백단위 표기) [선택됨]
4

전용 OCR 파서 실행 & 자동 캡처

확정된 기종의 전용 규칙(순위 슬라이싱 여부, 2~4자리 필터링)에 맞춰 고속 OCR 및 합계 100,000점 검증이 진행됩니다.
