AMOS JP-EX 점수판 인식 기능 개발 프리뷰 (ELI5)

작업 ID: jp-ex-score-recognition 리비전: 1 모드: canonical
요약: 오프 마장(역곡) 실전 사진을 기반으로 AMOS JP-EX 전탁의 3자리 LED(100점 단위) 점수판을 정확히 인식하고, 10,000점 미만 2자리 표기(`97` = 9,700점) 탈락 버그를 수정한 뒤 실측 픽스처로 검증합니다.

1. 하드웨어 표기 방식 비교

구분 AMOS REXX 3 AMOS JP-EX (역곡 실측)
표시 자릿수 4자리 고정 (`1 250`) 2~3자리 백단위 (`97`, `220`)
순위 세그먼트 내 자리 1자리 존재 (슬라이싱 필요) 순위 세그먼트 없음 (슬라이싱 금지)
배치 구조 T-형 전면 패널 다이아몬드 (상/하/좌/우)
점수 단위 100점 단위 100점 단위 (합계 1,000 = 10만점)

3. 핵심 결함 수정 및 변경 사항

기존 코드의 문제점 (AS-IS)

  • g.length >= 3 && g.length <= 4 조건으로 인해 2자리 점수(97, 26)가 필터에서 탈락하여 즉시 인식 실패(empty()).
  • JP-EX 테스트가 REXX 3 픽스처를 재활용한 가짜 단위 테스트에 불과함.
  • 카메라 스캔 및 UI에서 모델명이 'amos_rexx3'로 하드코딩됨.

수정 후 동작 (TO-BE)

  • 하한값 완화: g.length >= 2 && g.length <= 4로 수정하여 10,000점 미만 2자리 정상 인식.
  • 진짜 픽스처 도입: 역곡 클린 사진(KakaoTalk_20230528_2.jpg) 기반 RGB/마스크 픽스처 신규 등록.
  • 모델 선택 지원: UI 및 스캔 옵션에 amos_jp_ex 모델 전달 경로 구축.
주의 (Red Team 검증 결과): 사진 중 KakaoTalk_20230528_1.jpg의 5자리 표기(48700 등)는 사용자가 카카오톡에서 덧칠한 스티커 오버레이입니다. 전탁 하드웨어에는 5자리 모드가 존재하지 않으므로, 텍스트 스티커가 없는 순수 클린 사진(KakaoTalk_20230528_2.jpg)을 기준 픽스처로 사용합니다.
