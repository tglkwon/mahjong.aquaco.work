# 실시간 점수판 스캔 및 모바일 촬영

홈 또는 메뉴의 **사진·영상 점수 인식 베타** (`/set_score_photo`)에서 사용합니다.

1. **지원 작탁**: MVP는 AMOS REXX 3의 붉은 LED 점수판만 지원합니다. 아래쪽 대형 디스플레이의 맨 앞 순위 1자리는 점수에서 제외합니다. 기존에 저장된 다른 기종 설정도 적용하지 않습니다. JP-EX와 JP-Color는 REXX 3 MVP 이후에 추가합니다.
2. **실시간 스캔**: `[실시간 스캔 시작]`을 누르고 카메라 권한을 허용합니다. 후면 카메라 영상에서 초당 최대 5회 점수를 읽습니다. 같은 네 점수가 5회 이상, 1초 이상 유지되고 설정한 합계와 맞으면 한 번만 자동 캡처하고 카메라를 종료합니다. 인식이 끊기거나 값이 달라지면 연속 확인을 처음부터 시작합니다. `[스캔 중지]`나 `[직접 입력]`으로 중단할 수 있습니다. 화면을 벗어나거나 플레이어 목록이 바뀌어도 스캔을 중지합니다.
   - 대체 입력: `[📷 점수판 촬영하기]`로 사진을 촬영할 수 있습니다. 데스크톱에서는 파일 선택 창을 사용합니다.
3. **기록자 규칙**: 동가가 촬영하고 기록합니다. 동가의 점수가 화면 아래로 오도록 **가로 방향**으로 촬영합니다.
   - 기본 배정: **아래쪽→P1 · 오른쪽→P2 · 위쪽→P3 · 왼쪽→P4**. 현재 동가가 P1이 아니면 배정을 조정합니다.
4. **90° 회전 보정**: 세로로 촬영되었거나 방향이 어긋난 경우 `[⟲ 90° 회전]` 버튼을 누르면 이미지가 90도 회전되며 점수가 자동으로 다시 판독됩니다.
5. **점수 및 플레이어 확인**: `[점수 배정 한 자리 이동]`을 누르면 사진 위치와 표시값은 유지되고 선택한 네 플레이어 배정이 순환합니다. 기본 배정에서 한 번 누르면 아래쪽→P2 · 오른쪽→P3 · 위쪽→P4 · 왼쪽→P1이 됩니다. 네 번 누르면 원래 배정으로 돌아옵니다. 개별 플레이어 선택도 가능하며, 배정 변경 후에는 확인 체크가 해제됩니다. 처리 중이거나 기록을 확정한 상태에서는 이동할 수 없습니다. 표시 단위(기본 100점), 기준 합계(기본 100,000점)를 확인하고 불확실한 값은 직접 수정합니다.
6. **기록 확정**: 자동 캡처는 기록 확정이 아닙니다. 점수·단위·플레이어 확인에 체크한 뒤 `[확정하고 기록에 추가]`를 누릅니다. 합계 불일치, 빈 값, 플레이어 중복 시 기록이 차단됩니다. 다음 기록은 스캔을 다시 시작합니다.
7. **공유**: 확정한 기록은 URL 해시(`ScorePhotoInputPage`)로 저장되어 링크 공유가 가능합니다.

원본 사진과 캔버스 프레임은 서버로 전송하거나 저장하지 않으며, 전적으로 사용자 기기(브라우저 메모리)에서만 처리됩니다.

스캔은 HTTPS 사이트에서 카메라 권한을 허용해야 사용할 수 있습니다. 마이크는 요청하지 않습니다. 테스트할 때는 PC 개발 서버와 Cloudflare 터널을 켜 두고 휴대폰의 LTE·5G로 HTTPS 링크에 접속할 수 있습니다. PC와 휴대폰이 같은 Wi-Fi에 있을 필요는 없습니다.

## 검증 범위

2026-09-13 점수 배정 변경 검증: 모바일 실기기 테스트는 사용자 일정에 따라 보류합니다. 0/8 구분의 다양한 촬영 조건 검증과 타 기종 샘플 검증은 후속 작업입니다. 점수 배정 변경은 자동 테스트로 순환 복구, 표시값 보존, 확인 해제, 확정 시 배정 전달, 처리 중·확정 후 비활성화를 검증합니다.

- `node node_modules/react-scripts/bin/react-scripts.js test --watchAll=false --runInBand`: 9개 스위트, 41개 테스트 통과.
- `npx tsc --noEmit`: 통과.
- `npm run build`: 통과. 샌드박스의 `spawn EPERM`으로 최초 실행이 중단되어 승인된 재실행으로 검증했습니다.
- 독립 코드 검토: 수정이 필요한 문제 없음. 이번 변경의 브라우저 E2E와 모바일 실기기 검증은 수행하지 않았습니다.

후속 실시간 스캔 구현의 최신 검증 결과는 [실시간 스캔 검증 기록](ai/live-score-scan/evidence.ko.md)을 참고합니다. 기존 REXX 3 영상의 H.264 변환본을 브라우저 테스트에서만 가상 카메라로 공급해 실제 픽셀 인식부터 자동 캡처·자리 배정·기록·공유까지 검증합니다. 제품 코드에는 영상 테스트용 입력이나 카메라 우회 기능을 넣지 않습니다.

## 모바일 실기기 검증 방법 (Cloudflare HTTPS 터널)

PC와 스마트폰이 유선 랜/Wi-Fi/LTE 등으로 네트워크가 분리되어 있어도 다음 명령어로 모바일 실기기 테스트가 가능합니다.

```bash
# 1. 개발 서버 실행
npm start

# 2. 다른 터미널에서 HTTPS 터널 실행 (임시 HTTPS 주소 출력)
npm run test:mobile
```

터미널에 출력된 HTTPS 주소를 스마트폰의 Safari 또는 Chrome에서 열어 실제 카메라 연동 및 인식을 테스트할 수 있습니다.
