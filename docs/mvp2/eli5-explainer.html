한 게임의 흐름

01 / 이용자

공통 QR로 대기

가는 길에도 링크로 등록 가능.
회원 계정 또는 비회원 닉네임을 사용합니다.

02 / 직원

현장 도착 확인

현장에 있는지 수동 관리.
도착해도 온라인 순번은 그대로입니다.

03 / 다음 탁 구성

현장 대기자 4명 선정

등록 순번이 빠른 사람부터.
미도착자는 건너뛰고 순번은 보존합니다.

04 / 실제 참여자

자기 좌석 QR 등록

선정 명단과 달라도 허용.
각 좌석은 마지막 등록 완료자를 반영합니다.

05 / 네 자리 완료

활성 세션 1개

실제 참여자 4명을 대기에서 제외.
선정됐어도 안 앉은 사람은 대기에 남습니다.

06 / 결과 저장 성공

세션 종료

참여자·결과는 기록으로 보존.
다시 치려면 새 순번으로 재대기합니다.

시간 대신 순번

101 · A미도착 · 이번 선정 제외
102 · B현장 · 선정
103 · C현장 · 선정
104 · D현장 · 선정
105 · E현장 · 선정

예시 인물입니다. 재접속은 기존 순번 유지, 취소 후 재등록은 새 순번 발급.

이번 탁

B → C → D → E

A는 도착하면 101번 그대로 다음 선정에 참여합니다.

온라인에서 먼저 등록한 사람이 늦게 도착해도, 다음 선정에서는 더 앞설 수 있습니다. 현재 합의한 동작입니다.

게임을 마친 B·C·D·E가 다시 대기하면 새 순번을 받습니다. 게임 중 등록한 대기자가 자연스럽게 앞섭니다.

활성 테이블 수 = 네 자리 등록 완료 후 결과 저장 전인 테이블 수

결과 저장 후 다음 게임 재등록 전에는 활성 수가 줄어듭니다. 정상 동작이며 실제 매장 재실 인원을 뜻하지 않습니다.

이용자 · 대기

대기 등록 / 내 순번·현장 확인 상태 / 취소 / 게임 후 재대기

직원 · 대기 관리

전체 명단 / 도착 여부 변경 / 현장 순번에 따른 4명 선정

네 좌석의 계정·닉네임 / 등록 인원 / 선정 명단과 실제 명단 비교

세션 · 기록

등록 중·활성 상태 / 활성 테이블 수 / 저장 성공 후 종료 / 과거 결과 보존

예외에서도 지킬 규칙

같은 QR에 여러 번 등록

가장 최근에 등록을 완료한 사람으로 교체. 페이지를 열기만 해서는 바뀌지 않습니다.

선정과 착석이 다름

허용합니다. 실제 착석 명단으로 기록하고, 네 자리 완료 시 실제 참여자를 대기에서 제외합니다.

저장 실패

세션을 유지해 다시 시도합니다. 저장 성공 전에 테이블을 비우지 않습니다.

같은 결과 재전송

종료된 세션에 결과를 다시 제출해도 중복 기록하지 않습니다.

추가 결정 필요

아직 규칙으로 확정하지 않은 부분

편성·등록 중의 중복 배정과 좌석 교체

선정된 사람이나 일부 좌석 등록자를 다른 탁에서 잠시 제외할지, 활성화 후 자리 교체 시 대기 순번을 어떻게 복원할지는 미정입니다.

직원 조작과 방치된 등록 정리

선정 실행 방식, 미완성 세션 취소 권한, 부재·영업 종료 정리 기준을 정해야 합니다.

비회원 식별과 점수 시스템 연결

다른 기기·브라우저로 접속한 비회원의 복구 방식, MVP 1 결과를 해당 세션에 연결하는 인터페이스는 별도 정의가 필요합니다.

범위 밖: 추첨, 시각 기반 우선순위, 자동 재대기, 실제 재실 인원의 자동 감지.
